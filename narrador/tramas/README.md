# Tramas reservadas

Estruturas de aventura e consequências possíveis, sem materialização automática.

- `arcos/`: progressão e pressões de arcos;
- `direcoes/`: destinos canônicos de longo prazo;
- `dungeons/`: estruturas exploráveis preparadas;
- `oportunidades/`: elegibilidade para novos fios;
- `sidequests/`: contratos canônicos, emergentes e vivos;
- `recompensas/`: envelopes e itens possíveis;
- `ponte-de-kozakura/`: direção específica da campanha;
- `segredos/`: verdade reservada e lacunas controladas.

Uma direção, possibilidade ou recompensa preparada não é fato até confirmação
legítima pelo fluxo transacional.
