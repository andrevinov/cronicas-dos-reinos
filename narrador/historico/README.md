# Histórico reservado

Preparação e registros ocultos de sessões concluídas. O conteúdo é preservado
como evidência do ponto no tempo em que foi escrito; referências antigas dentro
dele não são rotas operacionais atuais.

Não consultar esta árvore para retomada comum. Use o histórico estruturado e só
aprofunde quando uma lacuna concreta exigir.
