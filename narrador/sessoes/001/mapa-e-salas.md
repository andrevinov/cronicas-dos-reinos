# Sessão 001: mapa operacional do porto

Arquivo reservado ao narrador.

Este não é um mapa exato de toda Ravens Bluff. É uma topologia de jogo para manter consistência nas primeiras cenas.

---

## Topologia inicial

```text
Cais de Chegada
  -> Pátio de Carga
      -> Narwhal Manor / alfândega
      -> Fileira de Armazéns
          -> Escritório lateral
          -> Beco dos Fundos
              -> Fishtown
              -> Red Sail Tavern
      -> Caminho para o posto da City Guard / Night Watch
  -> The Silver Lily
  -> The Happy Stein
```

Se Ren se deslocar por esta área, preservar esses vínculos salvo alteração causada por evento.

---

## Área A: Cais de Chegada

Descrição pública:

O cais está úmido, cheio de cordas, vozes, carga empilhada e marinheiros tentando resolver a última burocracia antes da noite.

Perceptível:

* fiscais recolhendo documentos;
* carregadores acelerando trabalho;
* gente evitando patrulheiros;
* tavernas começando a encher.

Segredo:

* uma pessoa observa quem pergunta por passageiros estrangeiros;
* um registro alterado está ligado ao pátio de carga, não ao cais em si.

Saídas:

* Pátio de Carga;
* The Silver Lily;
* The Happy Stein;
* rua para mercados.

Testes possíveis:

* Percepção CD 12 para notar a discussão no pátio;
* Intuição CD 13 para perceber medo em carregadores;
* Investigação CD 14 para entender que as cargas seguem uma ordem formal.

---

## Área B: Pátio de Carga

Descrição pública:

Caixas, barris e fardos passam por uma zona de conferência antes de seguirem para alfândega ou armazéns.

Perceptível:

* uma fila de cargas marcadas;
* um fiscal irritado;
* uma carregadora evitando conversa;
* marcas recentes no barro e na madeira.

Segredo:

* uma carga foi retirada da fila por ordem irregular;
* alguém pagou para a lacuna parecer erro de contagem;
* Mara Tharle viu parte da retirada.

Saídas:

* Cais de Chegada;
* Narwhal Manor;
* Fileira de Armazéns;
* posto da City Guard / Night Watch.

Testes possíveis:

* Investigação CD 13 para notar ordem de carga inconsistente;
* Percepção CD 12 para ver marcas de arrasto;
* Furtividade CD 13 para seguir alguém saindo do pátio;
* Persuasão CD 12 para acalmar Mara se Ren abordar sem pressão.

---

## Área C: Narwhal Manor / alfândega

Descrição pública:

Prédio funcional de registros, impostos e cargas retidas.

Perceptível:

* guardas e escrivães;
* filas de capitães e representantes;
* portas internas trancadas;
* cheiro de papel úmido e cera.

Segredo:

* Velis Rook alterou ou permitiu alterar um registro;
* ele teme mais seus credores do que a guarda comum;
* uma busca formal sem autorização pode ser bloqueada.

Saídas:

* Pátio de Carga;
* escritórios internos;
* rua lateral para armazéns.

Testes possíveis:

* Persuasão CD 15 para obter consulta sem autoridade;
* Intimidação CD 13 para assustar Velis, com risco de reputação;
* Intuição CD 14 para perceber evasão;
* Investigação CD 13 se Ren obtiver acesso a papéis.

---

## Área D: Fileira de Armazéns

Descrição pública:

Depósitos de madeira e pedra, portas largas, janelas altas, telhados baixos e vielas estreitas entre paredes.

Perceptível:

* algumas portas ainda abertas;
* outras fechadas cedo demais;
* marcas de rodas e botas;
* um beco pouco iluminado.

Segredo:

* a carga desaparecida passou por um armazém intermediário;
* há uma rota de fuga para Fishtown;
* capangas podem tentar atrasar Ren, não necessariamente matá-lo.

Saídas:

* Pátio de Carga;
* Escritório lateral;
* Beco dos Fundos;
* Red Sail Tavern.

Testes possíveis:

* Furtividade CD 13 para observar sem ser visto;
* Percepção CD 14 para notar vigia discreto;
* Investigação CD 13 para seguir marcas de carga;
* Acrobacia CD 12 para usar caixas, corrimãos ou telhados baixos em perseguição.

---

## Área E: Escritório lateral

Descrição pública:

Sala pequena de conferência ou controle, com mesa, prateleiras, lamparina e armário de documentos.

Perceptível:

* janela estreita para o pátio;
* papéis descartados;
* poeira mexida;
* cheiro de cera recente.

Segredo:

* pode conter uma pista parcial, mas não prova final;
* se Ren fizer barulho, alguém no beco pode fugir;
* um compartimento simples pode esconder recibo, lacre ou pedaço de tecido.

Saídas:

* Fileira de Armazéns;
* janela para área externa;
* porta dos fundos para beco, se fizer sentido em cena.

Testes possíveis:

* Investigação CD 13 para achar pista;
* Ferramentas de ladrão CD 12 para abrir gaveta simples;
* Furtividade CD 14 para investigar sem alertar o beco.

---

## Área F: Beco dos Fundos

Descrição pública:

Passagem estreita entre armazéns e construções menores, com barro, água escura e cheiro de peixe velho.

Perceptível:

* pegadas recentes;
* sombra de telhados;
* portas traseiras;
* som distante de taverna.

Segredo:

* rota de fuga para Fishtown;
* Dain ou outro intermediário pode aparecer aqui;
* combate aqui deve ter rotas de escape e cobertura.

Saídas:

* Fileira de Armazéns;
* Fishtown;
* Red Sail Tavern;
* pátio menor sem saída, se necessário.

Testes possíveis:

* Percepção CD 12 para não perder alguém na névoa;
* Furtividade oposta se Ren seguir alvo;
* Acrobacia CD 12 para cortar caminho;
* Atletismo CD 12 para escalar muro baixo.

---

## Área G: Red Sail Tavern

Descrição pública:

Taverna mais áspera, cheia de marinheiros, trabalhadores cansados, jogo pequeno e conversas que param quando entra gente errada.

Segredo:

* Dain pode ser encontrado ou mencionado aqui;
* testemunhas podem saber sobre a carga, mas exigem pagamento, favor ou privacidade;
* briga pública chama guarda rápido demais.

Saídas:

* rua do porto;
* beco dos fundos;
* caminho para Fishtown.

Testes possíveis:

* Intuição CD 13 para escolher interlocutor menos perigoso;
* Persuasão CD 12 com pagamento ou respeito;
* Intimidação CD 14 com risco de briga;
* Percepção CD 14 para notar observador.

---

## Área H: Posto da City Guard / Night Watch

Descrição pública:

Ponto de reunião mais prático do que nobre, com patrulheiros, banco de espera, armas simples e mural de recados.

Segredo:

* Luath precisa de ajuda, mas não quer parecer desesperado;
* há pressão para evitar acusações públicas contra gente influente;
* aceitar patrulha dá acesso, mas também torna Ren visível.

Saídas:

* Pátio de Carga;
* ruas internas;
* rota de patrulha noturna;
* quartel maior, se necessário.

Testes possíveis:

* Persuasão CD 12 para conseguir audiência útil;
* Intuição CD 13 para entender que Luath mede riscos;
* História ou Investigação CD 12 para interpretar mural de ocorrências.
