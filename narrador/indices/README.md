# Índices reservados

Contratos pequenos que roteiam consultas sem abrir toda a área do narrador.

- `estrutura.yaml`: autoridades, raízes e exceções estruturais;
- `continuidade-autoral.yaml`: continuidade de autoria;
- `populacao-canonica.yaml`: classificação fria dos NPCs canônicos;
- `presencas-incidentais.yaml`: política de presença incidental.

Índice aponta; não cria presença, conhecimento, acontecimento ou autoridade nova.
