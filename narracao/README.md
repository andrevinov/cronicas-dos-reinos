# Narração

Contratos públicos de como a campanha é narrada.

- [`principios/guia-de-narrativa.md`](principios/guia-de-narrativa.md): voz, ritmo e condução;
- [`principios/limites.md`](principios/limites.md): limites de conteúdo;
- [`operacao/protocolo-de-sessao.md`](operacao/protocolo-de-sessao.md): abertura, andamento e encerramento de sessão.

Esta árvore não contém segredos nem estado do mundo. Material reservado pertence
a `narrador/`; procedimentos técnicos do agente pertencem a `docs/agente/`.
