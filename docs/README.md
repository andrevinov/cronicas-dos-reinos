## Estrutura

- [`agente/`](agente/README.md): manuais operacionais vigentes, organizados por domínio;
- [`referencia/`](referencia/): referências estáveis de ferramentas e registros de migração;
- [`roadmaps/`](roadmaps/): propostas ainda não implementadas, separadas do manual atual.

Uma regra só pertence a `agente/` se estiver vigente. Decisão futura pertence a
`roadmaps/`; evidência histórica não deve voltar a competir com o manual corrente.
